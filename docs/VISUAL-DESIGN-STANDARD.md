# Graphify-Jev 可视化设计原则与 ComfyUI 卷帘工程规范 (Visual Design Standard)

> **版本**：v1.1 (2026-09-27)  
> **核心目标**：锁定经过真实业务验证的【纯单 Canvas 统一摄像机】+【ComfyUI 激光卷帘对比】黄金交互规范，杜绝后续迭代回退到脆弱的双 ECharts 或拥挤大水球。

---

## 1. 为什么坚决使用单一 HTML5 Canvas 统一摄像机？

在以往的探索中，曾尝试在同一个页面上叠放两个独立的 ECharts 实例，并通过 `dispatchAction` 去同步缩放与平移，但暴露了不可调和的底层缺陷：
- **微任务延迟与拖影**：两个实例各自跑自己的事件循环，鼠标拖拽时必然出现一个先动一个后动的视觉脱节；
- **缩放中心点漂移**：ECharts 对非原生事件的 zoom 锚点处理存在精度丢失，多次缩放后双图视口严重偏离；
- **DOM 遮挡**：顶层画布阻挡事件，导致“有时拖得动、有时拖不动”。

### ✅ 规范方案：纯单一 Canvas 统一物理视口（Unified Viewport Camera）
- 全屏只保留**唯一一个全尺寸 HTML5 2D Canvas**；
- 维护唯一的全局视口变换矩阵：`cameraX`、`cameraY`、`cameraZoom`；
- 在同一个 `requestAnimationFrame` / `render()` 循环内：
  1. 通过 `ctx.save(); ctx.rect(0, 0, curtainX, H); ctx.clip();` 绘制改造前 (Before)；
  2. 通过 `ctx.save(); ctx.rect(curtainX, 0, W - curtainX, H); ctx.clip();` 绘制改造后 (After)；
  3. 绘制垂直发光激光分割线。
- **收益**：**在数学上 1000% 绝对镜像锁死对齐，0 延迟、0 掉帧、60 FPS 极致性能！**

## 2. 节点球体造型与呼吸间距规范

节点球体必须兼顾“微型星尘的灵动感”与“深邃的立体层次感”，严禁绘制单调的单色纯圆或臃肿贴连的大水球。

### 2.1 双层嵌套立体环 (Dual-Ring Layering)
每个节点由内外两层同心结构绘制而成：
1. **外围高亮发光环 (Outer Ring)**：
   - 带有外发光柔和光晕（`shadowBlur: 8~24px`）；
   - 描边环颜色（良性为白绿 `#a7f3d0`，普通中枢为浅蓝 `#bae6fd`，恶性病灶为纯白 `#ffffff`）。
2. **核心内胆球体 (Inner Core)**：
   - 半径比外环收缩 `2.0px`，填充独立的饱满内胆色（`innerColor`），形成外环裹着内胆的水滴立体质感。

### 2.2 节点尺寸黄金梯队 (避免拥挤贴连)
- **恶性上帝病灶巨星**：基准半径 $15\text{px}$（直径 $30\text{px}$，配深红强烈发光）；
- **重构健康门面**：基准半径 $10\text{px}$（直径 $20\text{px}$）；
- **解耦微模块 (Pipeline Submodules)**：基准半径 $8\text{px}$；
- **普通依赖与业务节点**：基准半径严格控制在 $5.2\text{px} \sim 8.0\text{px}$，保持舒适的星空留白呼吸感；
- **缩放缓释算法**：绘制半径计算公式为 $r = \text{baseR} \times \text{zoom}^{0.65}$，放大画布时球体不会失控爆炸膨胀。

## 3. 连线与箭头规范

- **严格禁止三角形箭头**：
  在稠密的代码调用网络中，箭头会导致画面极度杂乱并遮挡相邻小球。
- **纯净微弧度光轨 (Curved Smooth Trails)**：
  连线两端纯净无箭头，使用二次贝塞尔曲线（`ctx.quadraticCurveTo`）产生与 ECharts 相同的优雅微弧度（`curveness: 0.12`）；
  普通连线采用半透明细光轨（宽度 $1.0\text{px}$，透明度 $0.22$）；
  仅对涉及恶性病灶的调用链使用红色高亮强化。

---

## 4. 节点文字标签 100% 全量覆盖与字色规范

- **100% 全覆盖**：
  严禁根据度数阈值过滤文字！所有节点必须在其球体右侧以 `9.5px ~ 11px` 精致字号清晰标注完整的函数名或模块名。
- **改造前后字色精准对齐**：
  - **激光线左侧（Before 改造前）**：文字全量呈现高警示粉红/红色（`#fca5a5`）；
  - **激光线右侧（After 改造后）**：文字全量呈现清新健康的翠绿色（`#6ee7b7`）；
  - 激光分割线划过时，节点文字与球体色彩实时同轴跃迁！

## 5. 交互控制规范：长按平移 vs 单击定格

用户在审查代码时，既需要全景漫游，又需要定格查阅，因此必须严格实施意图分流：
- **鼠标长按拖拽（移动位移 $> 3\text{px}$）**：
  判定为画布平移（Pan），光标变为 `grabbing` 抓手，视口随鼠标自由漫游；松开后**绝不改变锁定状态**。
- **原地轻点单击（移动位移 $< 3\text{px}$）**：
  判定为锁定/解锁切换：
  - 点击左键：激光画卷立刻**原地定格锁定**，分割线变为暖金琥珀光（Amber Glow），光标自由移出画卷，悬停任意小球查看 Tooltip 详情；
  - 再次点击左键：画卷在当前光标位置重新激活绑定，继续跟随漫游。
- **滚轮缩放**：
  以当前光标在视口上的绝对坐标为几何锚点（Anchor Zooming），放大缩小不飘移。
